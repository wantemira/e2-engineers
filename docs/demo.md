# Демонстрационный сценарий

Запустите приложение через `make up`, проверьте готовность контейнеров командой `make ps` и откройте `http://127.0.0.1:5173/`. Для исходного PR выполните `make demo-reset`: диалоги и квитанции сохранятся. Отдельная приватная сессия браузера даёт новый диалог.

Сценарий работает в Demo без ключа либо в Live с настроенным API модели. Режим отображается в шапке. Git, CI и профильные помощники в обоих режимах демонстрационные.

| Шаг | Ожидаемый результат |
| --- | --- |
| «Что писать в описании задачи?» | Ответ по командному документу со ссылкой на раздел. |
| «Как получить доступ к Grafana?» | Инструкция Viewer и ссылка на демо-заявку. Права не выдаются автоматически. |
| «Как получить доступ к GitLab CI/CD?» → согласие на черновик | Сообщение об отсутствии инструкции и черновик вопроса наставнику без отправки. |
| «Проверь PR #17» | Отчёт для SHA `a13d9c2…`, замечание о потере причины ошибки и FAILED у `TestCreateRepositoryError` в mock CI. |
| Ссылка `файл:строка`, затем «Объясни замечание 1» | Нужная строка сохранённого diff и объяснение замечания. |
| «Обновить AI-анализ» | Новый анализ с последним доступным результатом CI, без нового запуска CI. |
| «Имитировать запуск CI и обновить анализ» | Новый синтетический run ID для того же SHA; код PR не исполняется. |
| `make demo-fixed`, затем обновление анализа | Отчёт для SHA `c84be19…`, PASSED и исправленный diff. Предыдущий отчёт доступен в истории. |
| «Отправить наставнику» → подтверждение | Квитанция «Запрос создан в демонстрационном Git-сервисе» с проверенным SHA. |
| Обновление страницы | Сохранённые диалог, отчёты и квитанция. |

В Live формулировки и число рекомендаций зависят от модели. Ошибка провайдера отображается как ошибка операции с доступным повтором; Demo-ответ не подставляется. Настройка и коды ошибок описаны в [документации LLM](llm.md).
