# Контекст Backend-команды

Этот каталог содержит синтетический командный контекст проекта AI-Buddy. Он подготовлен для разработки интеграций и не описывает внутренние регламенты Авито.

Команда Backend разрабатывает Go-сервисы. В рабочем прототипе разрешён репозиторий e2-engineers и подготовленный PR №17. Наставник задан в context.json.

## Помощь

Помогу разобраться в правилах Backend-команды и подготовить PR к ревью. Сейчас доступен PR №17. Напишите «Проверь PR #17» для самопроверки. После проверки можно обсудить замечания, проверить исправленную версию и подтвердить отправку наставнику. Также можно спросить, где запускать тесты, как запросить доступ или к кому обратиться с организационным вопросом.

## Обращение к наставнику

Подготовьте ссылку на задачу или PR, ожидаемый результат, фактический результат и текст ошибки. Добавьте, какие проверки уже выполнили и какое решение хотите обсудить. Имя наставника берётся из конфигурации команды.
