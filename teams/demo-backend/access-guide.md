# Доступ к рабочим инструментам

Документ задаёт пример процесса для проекта AI-Buddy. Адрес действующей корпоративной системы заявок должен предоставить владелец команды.

## Доступ к инструменту

Укажите инструмент или репозиторий, необходимый уровень доступа и рабочую задачу. Передайте эти сведения наставнику для согласования по процессу команды. Не отправляйте пароли, токены и приватные ключи в чат. Если рабочая форма заявки пока неизвестна, уточните её адрес у наставника. В этом диалоге можно подготовить текст обращения с названием инструмента, причиной и требуемыми правами.
